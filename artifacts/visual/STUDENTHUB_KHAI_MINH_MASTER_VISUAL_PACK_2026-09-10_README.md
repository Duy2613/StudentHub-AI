# StudentHub AI / Khai Minh master visual pack

Generated 2026-09-10 for the final visual and product integration pass.

This pack contains the supplied visual references, one text-free generated hero reference, a SHA-256 inventory, responsive derivatives, route mapping, provenance, safe-use policy, crops, and a small preview contact sheet.

## Source truth

Every supplied PNG is classified as `ILLUSTRATIVE_CONCEPT_ART`. Its embedded labels, numbers, portraits, quotes, citations, testimonials, interface copy, case titles, and counts are not product data. The app renders meaningful text from its own route components and backend contracts.

The generated hero is also a visual reference. It was generated specifically without words, letters, numerals, logos, fake UI, or statistics so it can support a real product-rendered hero composition.

## Directory map

- `originals/source/`: the 21 supplied PNGs, retained with their original filenames.
- `originals/generated/`: the new text-free hero reference.
- `web/desktop/`, `web/tablet/`, `web/mobile/`: AVIF responsive derivatives.
- `web/og/`: wide derivatives for metadata or share surfaces.
- `web/decorative/`: blurred, low-detail decorative derivatives.
- `web/crops/`: square prism crops for controlled editorial use.
- `previews/`: selected-visual contact sheet.
- `manifest.json`: dimensions, hashes, risk labels, and derivative registry.
- `route-map.json`: route-to-visual mapping for active product routes.
- `provenance.json`: source and derivative lineage.
- `ASSET_USAGE_POLICY.md`: guardrails for illustrative art.

## Product serving rule

The web app serves only the responsive AVIF derivatives under `frontend/public/media/khai-minh/`. Original source PNGs are never served directly by the product UI.
