# Community Max Moderation Contract

All Community Max body, URL, media, source, campus, correction, and request
inputs pass the existing server-side Security Fabric and Community privacy
boundary. Moderation may hide, block, or request correction of Community
content and may create an appeal through existing moderation entities.

Moderation state is not a Trust state. A moderation decision must not write a
Trust verdict, evidence status, Expert qualification, Passport event, or
ranking authority. Appeals preserve the original revision and decision
lineage. Private moderator/risk data is never included in public DTOs,
notifications, summaries, search documents, or logs.
