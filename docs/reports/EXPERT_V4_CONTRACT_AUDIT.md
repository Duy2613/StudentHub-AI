The currently deployed schema lacks `private.expert_review_requests`; expected eight static Expert test accounts were absent. Local migrations include request linkage and authority snapshot changes, but none were applied during that discovery. No write test was run. This makes request persistence, assignments and assessment assurance `DEFERRED`; it does not weaken the UI implementation path.

## E0 decision

E0 closes for frontend implementation with these boundaries: use the durable `/api/v1/experts` and `/api/expert/profile/[expertId]` read contracts; treat repository-only richer DTO fields as absent when durable data omits them; submit only through the server-owned request/assessment APIs; keep assignment selection server-owned; never infer outside scope, public availability, credential lifecycle, public review, or a final Trust verdict. Database assurance remains deferred.
