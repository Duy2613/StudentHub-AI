## 1. Executive Diagnosis: Overcoming the "Black-Box AI" Trap

### 1.1 The Owner's Direct Mandates
> **Mandate B:** *"AI/advanced analysis layers do not present sufficiently strong evidence links. Each important conclusion should have clickable real sources."*  
> **Mandate G:** *"Backend/evidence/AI layers need to become substantially stronger."*

In StudentHub V2, the verification output fell into the classic generative AI antipattern:
*   A colorful badge declared "98% ĐỘ TIN CẬY" (98% Confidence) without an explanation of where that percentage came from or what mathematical method calculated it.
*   The reasoning text appeared as a monolithic paragraph generated by an LLM with vague generic claims like "Theo quy định hiện hành...".
*   Evidence sources were presented as static, unclickable cards or mock badges without live outbound HTTP links, publication timestamps, or verbatim quote snippets.
*   If a student clicked a source, they were not taken to the actual university registrar decree or circular PDF.

### 1.2 The V3 Epistemic Core: "Forensic Auditability"
In **V3**, StudentHub operates under the standard of **Academic & Legal Forensics**:
1.  **Every Conclusion Must Have a Paper Trail:** An AI conclusion is invalid unless every constituent proposition is mapped directly to a cryptographically hashed, retrieved source object.
2.  **No Unexplained Percentages:** Banish arbitrary confidence scores (e.g., "98% True"). Replace with structured epistemic dimensions: Institutional Authority, Multi-Source Corroboration, Freshness, and Verifiable Agreement/Disagreement.
3.  **Real, Clickable Outbound Sources:** Every cited source must provide a high-affordance external link with URL preview, publication date, domain trust tier, and verbatim quote context.
4.  **Full Claim $\leftrightarrow$ Source Transparency:** The user must be able to visually trace *why* a conclusion was reached by exploring explicit graph relationships.

## 2. Anatomy of the First-Class Evidence Source Object

In V3, an Evidence Source is not a footnote—it is a first-class visual and interactive object with a complete anatomical schema:

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│  [ PRIMARY_OFFICIAL ]  Đại học Quốc gia TP.HCM (vnuhcm.edu.vn)           [ LINK ↗ ]     │
│  Công văn số 142/ĐHQG-CTSV về Quy chế Học bổng Khuyến khích Học tập 2025-2026            │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│  Published: 14/08/2025  •  Retrieved: 08/09/2026 14:22 UTC  •  SHA-256: 4f8a...c01e       │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│  "Điều 4. Thời hạn nộp hồ sơ xét duyệt học bổng kết thúc trước 17h00 ngày 01/09/2026.    │
│   Mọi hồ sơ nộp sau thời điểm này đều bị coi là không hợp lệ."                           │
├──────────────────────────────────────────────────────────────────────────────────────────┤
│  RELATIONSHIP: 🟢 HỖ TRỢ CLAIM #1 (Có học bổng)  |  🔴 MÂU THUẪN CLAIM #2 (Thời hạn 15/09)│
├──────────────────────────────────────────────────────────────────────────────────────────┤
│  TRUST SIGNALS: 🏛️ Cơ quan ban hành cấp I  |  ⏱️ Còn hiệu lực văn bản  |  🔗 Độc lập 100% │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 Anatomical Attributes
1.  **Source Identity & Trust Tier:** Official Registrar (`PRIMARY_OFFICIAL`), Ministry of Education & Training (`GOVERNMENT_REGULATORY`), Peer-reviewed Academic (`ACADEMIC_PEER`), News Outlet (`JOURNALISTIC_ACCREDITED`), Student Community (`COMMUNITY_CORROBORATED`).
2.  **Verified Canonical Title & Domain:** Clean typography distinguishing the institutional publisher from the specific decree title.
3.  **URL Affordance:** Explicit, high-contrast outbound anchor with external link icon (`↗`), security attributes (`rel="noopener noreferrer"`), and domain badge.
4.  **Temporal Provenance:** Both `publishedAt` (when the document was signed) and `retrievedAt` (when StudentHub's crawler indexed it).
5.  **Verbatim Forensic Snippet:** The exact paragraph from which the conclusion was drawn, rendered in an editorial quote style with highlighted semantic keywords.
6.  **Claim Relationship Vector:** Explicitly declaring whether this source supports, contradicts, or contextualizes specific sub-claims.
7.  **Quality Explanation:** Clear qualitative justification (e.g., "Ban hành bởi Phòng Công tác Sinh viên ĐHQG; chữ ký số hợp lệ") instead of an arbitrary percentage.

## 3. Claim $\leftrightarrow$ Source Relational Visualization

To answer the user's primary mental question: *"Why did StudentHub conclude this?"*, the interface visualizes explicit bi-directional mappings:

```
[ USER CLAIM: "ĐHQG gia hạn nộp học bổng đến 15/09/2026" ]
                        │
                        ▼ (Claim Decomposition)
 ┌──────────────────────────────────────┬──────────────────────────────────────┐
 │ Claim A: "ĐHQG có cấp học bổng kỳ 1" │ Claim B: "Hạn nộp gia hạn đến 15/09" │
 └──────────────────────────────────────┴──────────────────────────────────────┘
            │                                      │
            ├──────────────────────────┐           ├──────────────────────────┐
            ▼                          ▼           ▼                          ▼
     [ Source #1: VNUHCM ]      [ Source #2: CTSV] [ Source #1: VNUHCM ]      [ Source #3: Diễn đàn ]
     🟢 SUPPORTS                🟢 SUPPORTS        🔴 CONTRADICTS             🟡 CONTEXTUAL
     "Quyết định 142/ĐHQG"      "Thông báo số 08"  "Hạn chót là 01/09"        "Tin đồn chưa xác thực"
```

### 3.1 Interaction Dynamics
*   Clicking **Claim B** in the Investigation Rail highlights **Source #1** with a red tension filament and dims all sources unrelated to Claim B.
*   Hovering **Source #1** spotlights the conflicting sentence in the claim input box and displays an inline diff:
    *   *Claim:* `15/09/2026`
    *   *Actual Registrar Text:* `01/09/2026` (Chênh lệch: $-14\text{ ngày}$).

## 4. The 8-Layer AI Verification Presentation Hierarchy

Rather than presenting an unverified generative summary, the V3 Result Stage displays information in strict epistemic order:

1.  **QUALITATIVE CONCLUSION (Monumental Display):** High-contrast editorial judgment (*XÁC THỰC CÓ ĐIỀU KIỆN*, *THÔNG TIN SAI LỆCH*, *CHƯA ĐỦ CĂN CỨ PHÁP LÝ*).
2.  **EVIDENTIARY BASIS:** 2–3 sentence executive brief citing exact legal/institutional decrees by reference tag (`[1]`, `[2]`).
3.  **AGREEMENT / DISAGREEMENT MATRIX:** Direct side-by-side comparison table between what the user claimed and what verified records prove.
4.  **SOURCE QUALITY AUDIT:** Breakdown of institutional authority tiers across all consulted documents (e.g., 2 Cổng thông tin ĐHQG, 1 Cổng Bộ GD&ĐT).
5.  **UNCERTAINTY BOUNDS:** Explicit declaration of what the AI *cannot* confirm (e.g., "Chưa thể xác minh chính sách riêng của từng khoa thành viên").
6.  **MISSING EVIDENCE GAPS:** What document is missing to make this 100% conclusive (e.g., "Chưa có thông báo chính thức từ Khoa CNTT").
7.  **NEUTRAL AI SYNTHESIS:** Technical explanation of the regulatory context.
8.  **ACTIONABLE NEXT STEPS:** Practical guidance for the student (e.g., "Liên hệ Phòng CTSV trước 17h hôm nay để nộp đơn cứu xét").

## 5. Inline Citation & Source Inspector System

### 5.1 Inline Citation Grammar
Within any narrative or analytical paragraph, citations appear as refined, interactive monospace tags:
```markdown
Quy chế học bổng năm học 2025-2026 áp dụng cho sinh viên đạt GPA từ 3.2 trở lên [1], 
tuy nhiên hạn chót nhận hồ sơ đã khép lại vào ngày 01/09 [1][2], trái với thông tin 
lan truyền trên mạng xã hội [3].
```

### 5.2 Micro-Interactions
*   **Keyboard Navigation:** Each citation tag is a native `<button>` element with `tabindex="0"`, `aria-haspopup="dialog"`, and `aria-label="Xem nguồn trích dẫn 1: Đại học Quốc gia TP.HCM"`.
*   **Hover/Focus Preview:** Displays a lightweight floating card (280px width) within 120ms:
    *   Publisher Logo + Domain
    *   Document Title
    *   Relevant Snippet with citation anchor
*   **Click Action:** Opens the **Source Inspector Drawer** on desktop (slides in from right, 420px width) or a swipeable **Bottom Sheet** on mobile viewports.
*   **Source Inspector Contents:**
    *   Full document metadata & SHA-256 retrieval hash.
    *   Verbatim extracted context (surrounding $\pm 300$ characters).
    *   Prominent outbound button: `"Mở văn bản gốc tại vnuhcm.edu.vn ↗"` (`target="_blank" rel="noopener noreferrer"`).
    *   Audit button: `"Báo cáo liên kết hỏng / nội dung thay đổi"`.

## 6. Backend-Contract-Aware Schema Specification

The frontend UX assumes the backend evidence retrieval and synthesis engine provides structured JSON conforming to the following tripartite contract:

```typescript
export interface EvidenceSourceDTO {
  // === REQUIRED FIELDS (Contract Non-Negotiable) ===
  evidenceId: string;              // Unique immutable UUID (e.g., "ev-2026-0908-01")
  claimId: string;                 // Foreign key to parent claim (e.g., "clm-scholarship-deadline")
  title: string;                   // Official title of the document or webpage
  url: string;                     // Canonical, clickable HTTP/HTTPS URL
  publisher: string;               // Name of institution/organization (e.g., "ĐHQG-HCM")
  sourceType: SourceType;          // 'PRIMARY_OFFICIAL' | 'GOVERNMENT_REGULATORY' | 'ACADEMIC_PEER' | 'COMMUNITY_CORROBORATED'
  retrievedAt: string;             // ISO-8601 UTC timestamp of retrieval
  snippet: string;                 // Verbatim excerpt (max 500 chars) used in synthesis
  supportsClaims: string[];        // Array of claim IDs this source positively corroborates
  contradictsClaims: string[];     // Array of claim IDs this source refutes or disputes
  qualitySignals: QualitySignals;  // Structured trust signals
  citationStatus: CitationStatus;  // 'ACTIVE_VERIFIED' | 'PAYWALLED' | 'ARCHIVED' | 'STALE'

  // === OPTIONAL FIELDS (Enriches UI when present) ===
  publishedAt?: string;            // ISO-8601 date of original publication/decree
  authorOrDepartment?: string;     // e.g., "Phòng Công tác Sinh viên"
  contentHash?: string;            // SHA-256 hash of retrieved payload for forensic immutability
  independenceRating?: number;     // 0.0 - 1.0 score of source neutrality
  retrievalMethod?: string;        // 'OFFICIAL_API' | 'HEADLESS_DOM_CRAWL' | 'ACADEMIC_INDEX'

  // === DERIVED FIELDS (Computed on Client / Presentation Layer) ===
  freshnessCategory: Freshness;    // 'HOURS_AGO' | 'RECENT_DAYS' | 'CURRENT_SEMESTER' | 'ARCHIVAL'
  relativeTimeFormatted: string;   // e.g., "Cách đây 2 ngày"
  domainClean: string;             // e.g., "vnuhcm.edu.vn"
}

export interface QualitySignals {
  institutionalAuthority: 'TIER_1_SOVEREIGN' | 'TIER_2_ACCREDITED' | 'TIER_3_AFFILIATED' | 'TIER_4_UNVERIFIED';
  domainTrust: number;             // 0 - 100 domain authority score
  corroborationCount: number;      // Number of independent sources agreeing with this point
}
```

## 7. Exhaustive Visual & Runtime State Matrix

The UI must gracefully handle all 20 operational states without crashing, flickering, or trapping the user:

| State Key | Visual Trigger / Status | Interface Presentation & User Feedback |
| :--- | :--- | :--- |
| **`idle`** | Default on `/trust` | Centered input instrument, ambient refractive optical lens, sample prompts. |
| **`invalid`** | Empty input, $<10$ chars, spam | Red input border shimmer, micro-mono warning: `Lỗi: Vui lòng nhập tối thiểu 10 ký tự hoặc tải văn bản PDF`. |
| **`running`** | Job submitted to orchestrator | Header compresses, secondary sections teardown, optical lens zooms into telephoto mode. |
| **`source_search`** | Crawler querying academic/gov indexes | Animated radar sweep in constellation stage; ticker: `Đang quét cổng văn bản ĐHQG...`. |
| **`claim_extraction`** | OCR/NLP decomposing text | FLIP animation fracturing input card into discrete claim tokens with blue tags. |
| **`evidence_retrieval`**| Sources arriving via SSE | Ingress physics: Source nodes fly into constellation from margins with spring damping. |
| **`comparison`** | Cross-referencing claims | Amber/green filaments connecting claims to sources; tension vectors animating. |
| **`insufficient`** | $<2$ sources found | Warning badge: `CHƯA ĐỦ CĂN CỨ KẾT LUẬN`. Prompt user to upload supplementary document. |
| **`conflict`** | Major contradiction detected | Split-screen contrast view; conflicting claims glow amber-red with side-by-side diff. |
| **`partial`** | 1 claim verified, 1 unresolved | Yellow cautionary banner: `XÁC THỰC MỘT PHẦN`. Clear badge for each claim. |
| **`provider_degraded`**| Fallback AI model invoked | Subtle info pill: `Hệ thống đang hoạt động ở chế độ dự phòng. Tốc độ kiểm chứng có thể chậm hơn`. |
| **`save_pending`** | Analysis bookmarking in progress | Cloud sync spinner in top rail. |
| **`save_failed`** | LocalStorage/DB write error | Inline toast: `Không thể lưu kết quả vào lịch sử. Vui lòng tải xuống bản PDF`. |
| **`persisted`** | Verification saved to permanent DB | Cryptographic run hash displayed (`STU-RUN-2026-98124`) with copy button. |
| **`result`** | Full synthesis complete | Crystalline caustic wash, Monumental Serif verdict, complete evidence bento. |
| **`cancelled`** | User hits `Esc` or "Hủy" | Immediate graceful reset; teardown unwinds; returns to `idle` in 240ms. |
| **`offline`** | Network disconnected (`navigator.onLine = false`) | Crimson status chip: `Mất kết nối mạng. Đang tự động kết nối lại khi có Internet...`. |
| **`stale_run`** | Viewing result $>30$ days old | Header alert: `Kết quả này được tạo từ 08/2026. Một số văn bản quy chế có thể đã được cập nhật`. |
